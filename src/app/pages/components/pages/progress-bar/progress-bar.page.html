Progress bars show a linear state for loading, uploading, or completion. They support determinate, indeterminate, query, and buffer modes while staying lightweight and flexible enough for status layouts.

Modes and states

A progress bar can be determinate, indeterminate, query, or buffer. For determinate states, use the [value] input. For buffer mode, also provide [bufferValue] to show the current target and the overall progress together.

Buffer and customization

Colors, variants, and sizing are controlled through the [color], [variant], and [size] inputs. The default appearance is a pill-shaped bar using the primary color, but you can also switch to a sharper look or a custom color scheme.

Keep in mind that mode="buffer" cannot be combined with size="auto". The component logs a warning when that forbidden combination is used.

Providing default values

Default values for the progress bar can be supplied with the provideProgressBarDefaults provider. This lets you set a consistent look across an application without repeating the same inputs everywhere.
