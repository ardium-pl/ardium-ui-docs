Checkboxes are a compact way to capture a boolean choice. They support standard selection states, a label, and a special indeterminate state for an intermediate value.

Using Checkboxes

A checkbox can be bound with Angular forms using [formControl] or [(selected)]. The model value is a boolean, while the component also exposes the richer [state] API for the special unselected, indeterminate, and selected states.

The following events are emitted:

  • (select) — fired when the checkbox becomes selected.
  • (unselect) — fired when the checkbox becomes unselected.
  • (selectedChange) — emits the current boolean value.
  • (stateChange) — emits the current CheckboxState.
  • (change) — aliases the boolean change event.
States and reversed semantics

The checkbox has three visual states via the [state] input: unselected, indeterminate, and selected.

In some cases, the meaning of the checked state is inverted. Use [reverseSelected] to flip the semantic meaning while keeping the UI consistent.

Customizing the checkbox

Checkboxes can be styled with a color, a custom icon, and custom label templates. Colors are defined by the SimpleComponentColor enum, and default values can be changed through the provider.

  • [color] — primary accent color used in the selected state.
  • [unselectedColor] — accent color used when the checkbox is unselected.
  • [label] — string or boolean label configuration, where null means no label.
  • [readonly] and [disabled] — disable interaction as usual for form controls.
Customizing with templates

The default icon can be replaced with a custom Angular template. Use ng-template marked with ard-checkbox-tmp directive, and the template receives the current selected state.

Providing default values

Default values of all checkbox properties can be provided with the provideCheckboxDefaults provider function. It accepts a partial defaults object and merges it with the library defaults.
